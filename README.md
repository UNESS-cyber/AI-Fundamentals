# Fundamentals of Artificial Intelligence

A structured collection of implementations, experiments, and concise explanations covering the core topics of a Fundamentals of Artificial Intelligence course.

This repository is part of my academic portfolio and is focused on understanding the concepts behind the algorithms, not simply calling high-level libraries.

## Topics

| Topic | Main concepts | Status |
|---|---|---|
| Regression | Linear regression, loss functions, gradient descent | In progress |
| Classification | Logistic regression, decision boundaries, metrics | In progress |
| Neural Networks | Forward pass, loss, backpropagation, optimization | In progress |
| CNNs | Convolution, pooling, feature extraction | Planned |
| Dimensionality Reduction | PCA, variance, eigenvectors | Planned |
| Sequence Models | RNNs, hidden states, sequence prediction | Planned |
| Reinforcement Learning | MDPs, Q-learning, policies, rewards | Planned |

## Repository philosophy

For each topic, I aim to include:

1. A short conceptual explanation
2. The relevant mathematical formulation
3. A simple implementation
4. A small experiment
5. Visualization of the result
6. A short interpretation

The goal is to understand **why** an algorithm works, not only **how** to call it.
